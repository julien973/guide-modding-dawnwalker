1 Vue d'ensemble & mécanique interne

A. Le fonctionnement des effets (Gameplay Effect)

Les statistiques et bonus des armes sont régis par le Gameplay Ability System (GAS) d'Unreal Engine :

  • L'asset d'arme expose un tableau de structures nommé CustomEffectParameters.
  • Chaque entrée de ce tableau associe une classe Blueprint dérivée (_C) à une valeur flottante (Value) injectée dans le moteur via l'attribut Stats.CustomModifier.

📐 Correspondance valeur interne → bonus en jeu

0.409 correspond au multiplicateur additif de +90 % en jeu. Autres valeurs observées sur cet asset : 0.227 → +50 %, -0.364 → −80 %.

B. Comprendre le FPackageIndex (champ Variant dans UAssetGUI)

Dans UAssetGUI, une ObjectProperty (comme le champ Effect) ne stocke pas le nom de la classe en texte brut. Elle utilise un FPackageIndex :

  • 0 : référence nulle (null).
  • Entier positif (> 0) : pointe vers la table d'Export Data (Index = Export − 1).
  • Entier négatif (< 0) : pointe vers la table d'Import Data.
Index réel de l'import dans la table = −Variant − 1

⚠️ Pourquoi ne pas mettre -1 sur toutes les lignes ?

Le chiffre -1 correspond au premier import de la table (GE_DamageAgainstCorruptedMultiplier_C). Si l'on met -1 pour les nouvelles entrées, le jeu appliquera de nouveau le bonus contre les Surnaturels. Pour cibler les Mortels ou les Animaux, il faut pointer vers leurs index d'import respectifs (-21 et -23).

Table de résolution des pointeurs dans l'asset :

C. Le format conteneur UE5 (Zen / IoStore)

UE5.5 utilise le conteneur IoStore composé de trois fichiers indissociables :

  1. .utoc — Table des matières / catalogue des chunks.
  2. .ucas — Données binaires compressées.
  3. .pak — Index de compatibilité.

Outils requis

  1. UAssetGUI — Éditeur binaire d'assets Unreal.

Structure stricte des dossiers

L'arborescence doit impérativement reproduire le chemin interne du jeu à partir d'un dossier racine (ex. dossier_mod_legacy) :

⚠️ Règle d'or

Un seul niveau de dossier en trop ou en moins et le jeu ne trouvera pas l'asset remplacé : le chemin doit refléter exactement la structure interne du pak d'origine.

4 Procédure technique pas à pas

1 Sauvegarde de sécurité

Copie toujours ton dossier de travail avant toute modification binaire :

robocopy "D:\Downloads\dossier_mod_legacy" "D:\Downloads\dossier_mod_legacy_BACKUP" /E

💡 Pourquoi robocopy plutôt que xcopy ?

robocopy est l'outil de copie moderne de Windows : il ne s'interrompt pas à la première erreur rencontrée, préserve les attributs et les horodatages des fichiers, et gère les chemins longs. Le paramètre /E copie tous les sous-dossiers, y compris les vides — exactement ce qu'il faut pour sauvegarder une arborescence de mod complète.

2 Ajout des 4 imports dans l'Import Data

Pour qu'Unreal Engine sache quelles classes charger, il faut déclarer chaque classe Blueprint (BlueprintGeneratedClass) ET son package parent (Package).

  1. Ouvrir ITM_Weapon_SwordDawnwalker5a.uasset dans UAssetGUI.
  2. Dans le panneau de gauche, cliquer sur Import Data.
  3. Faire défiler jusqu'à la dernière ligne existante (index -19).
  4. Sur la ligne vide tout en bas (marquée *), ajouter successivement les 4 entrées :
Ligne autoClassPackageClassNameOuterIndexObjectName
-20/Script/CoreUObjectPackage0/Game/_Dawnwalker/Stats/CustomItemModifiers/GE_DamageAgainstUntouchedMultiplier
-21/Script/EngineBlueprintGeneratedClass-20GE_DamageAgainstUntouchedMultiplier_C

-23/Script/EngineBlueprintGeneratedClass-22GE_DamageAgainstAnimalsMultiplier_C

Explications techniques des champs :

  • OuterIndex — Lie la classe à son dossier/package parent. La ligne -21 a un OuterIndex de -20 pour indiquer qu'elle appartient au package de la ligne -20.

🚫 Ne jamais utiliser le préfixe Default__…

Il pointe vers le Class Default Object (CDO), ce qui ferait échouer l'application de l'effet.

1 Overview & internal mechanics

A. How effects work (Gameplay Effect)

Weapon stats and bonuses are governed by Unreal Engine's Gameplay Ability System (GAS):

  • The weapon asset exposes an array of structs named CustomEffectParameters.
  • Each entry in this array associates a derived Blueprint class (_C) with a floating-point value (Value) injected into the engine through the Stats.CustomModifier attribute.

📐 Internal value → in-game bonus mapping

0.409 corresponds to the additive multiplier of +90 % in game. Other values observed in this asset: 0.227 → +50 %, -0.364 → −80 %.

B. Understanding FPackageIndex (the Variant field in UAssetGUI)

In UAssetGUI, an ObjectProperty (such as the Effect field) does not store the class name as plain text. It uses an FPackageIndex:

  • 0: null reference (null).
  • Positive integer (> 0): points to the Export Data table (Index = Export − 1).
  • Negative integer (< 0): points to the Import Data table.
Real import index in the table = −Variant − 1

⚠️ Why not use -1 on every row?

The value -1 corresponds to the first import in the table (GE_DamageAgainstCorruptedMultiplier_C). If you set -1 for the new entries, the game will apply the Supernatural bonus again. To target Mortals or Animals, you must point to their respective import indexes (-21 and -23).

Pointer resolution table for this asset:

-1Import #0 — GE_DamageAgainstCorruptedMultiplier_CExisting effect (Supernaturals)
-20Import #19 — Package /Game/_Dawnwalker/Stats/CustomItemModifiers/GE_DamageAgainstUntouchedMultiplierParent package (added)
-21Import #20 — Class GE_DamageAgainstUntouchedMultiplier_CEffect of index 4 (Mortals)
-22Import #21 — Package /Game/_Dawnwalker/Stats/CustomItemModifiers/GE_DamageAgainstAnimalsMultiplierParent package (added)
-23Import #22 — Class GE_DamageAgainstAnimalsMultiplier_CEffect of index 5 (Animals)

C. The UE5 container format (Zen / IoStore)

UE5.5 uses the IoStore container made of three inseparable files:

  1. .utoc — Table of contents / chunk catalog.
  2. .ucas — Compressed binary data.
  3. .pak — Compatibility index.

4 Step-by-step technical procedure

1 Safety backup

Always copy your working folder before any binary modification:

robocopy "D:\Downloads\dossier_mod_legacy" "D:\Downloads\dossier_mod_legacy_BACKUP" /E

💡 Why robocopy instead of xcopy?

robocopy is Windows' modern copy tool: it does not stop at the first error, preserves file attributes and timestamps, and handles long paths. The /E parameter copies all subdirectories, including empty ones — exactly what you need to back up a complete mod tree.

2 Adding the 4 imports to the Import Data

For Unreal Engine to know which classes to load, each Blueprint class (BlueprintGeneratedClass) AND its parent package (Package) must be declared.

  1. Open ITM_Weapon_SwordDawnwalker5a.uasset in UAssetGUI.
  2. In the left panel, click Import Data.
  3. Scroll down to the last existing row (index -19).
  4. On the empty row at the very bottom (marked *), add the 4 entries in sequence:
Auto rowClassPackageClassNameOuterIndexObjectName
-20/Script/CoreUObjectPackage0/Game/_Dawnwalker/Stats/CustomItemModifiers/GE_DamageAgainstUntouchedMultiplier
-21/Script/EngineBlueprintGeneratedClass-20GE_DamageAgainstUntouchedMultiplier_C
-22/Script/CoreUObjectPackage0/Game/_Dawnwalker/Stats/CustomItemModifiers/GE_DamageAgainstAnimalsMultiplier
-23/Script/EngineBlueprintGeneratedClass-22GE_DamageAgainstAnimalsMultiplier_C

Technical explanation of the fields:

  • OuterIndex — Links the class to its parent folder/package. Row -21 has an OuterIndex of -20 to indicate it belongs to the package of row -20.
  • _C suffix — Designates the generated Blueprint class required for GAS execution.

🚫 Never use the Default__… prefix

It points to the Class Default Object (CDO), which would cause the effect application to fail.

6 Saving and integrity check

  1. Do File > Save (Ctrl+S).
  2. Close UAssetGUI completely.
  3. Reopen the file.
  4. Check that:
  • CustomEffectParameters (6) is properly preserved.
  • Nodes 4 and 5 correctly show (2) children.
  • The class names GE_DamageAgainstUntouchedMultiplier_C and GE_DamageAgainstAnimalsMultiplier_C clearly display in green/blue next to their ObjectProperty.

💡 Why close and reopen?

Reopening forces UAssetGUI to re-read the file as it was written to disk. If a write was corrupted (missing name, orphaned index), that is when it shows up — well before a potential in-game crash.

5 Compiling with retoc (Zen format)

Open a command prompt (cmd.exe) in the folder containing retoc.exe. Run the command on one single continuous line:

.\retoc.exe to-zen --version UE5_5 "D:\Downloads\dossier_mod_legacy" "Sword_Of_SaintM_OP_P.utoc"

⚠️ Note

Under cmd.exe, do not use PowerShell continuation characters such as backticks `, or you will get "command not found" errors.

Checking the output files

retoc generates three files in the folder:

  • Sword_Of_SaintM_OP_P.utoc
  • Sword_Of_SaintM_OP_P.ucas
  • Sword_Of_SaintM_OP_P.pak

Verify that all three files are larger than 0 KB.

6 Installation & testing procedure

  1. Copy the 3 generated files into the game's mods directory:
...\The Blood of Dawnwalker\Dawnwalker\Content\Paks\~mods\
  1. Important: delete or move old versions of the mod to avoid any loading-priority conflict with the IoStore container.
  2. Launch the game and test in this order:
  • No crash when loading the menu / the save file.
  • Open the inventory and equip the weapon (if the binary reference was wrong, the game would crash when equipping).
  • Check damage: hit a human (+90 % applies) then an animal (+90 % applies).
